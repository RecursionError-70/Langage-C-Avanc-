# Langage-C-Avanc-
RUN &amp; DIE 

Notre projet, Run & Die, est un jeu de plateforme en 2D inspiré de Level Devil, que nous réalisons en langage C à trois. 

Le joueur doit atteindre la porte de sortie de chacun des 3 niveaux le plus vite possible, mais les règles changent en cours de partie à cause d’événements aléatoires : 
gravité modifiée, contrôles inversés, porte déplacée, personnage invisible ou immobilisé, pénalité en cas d’inactivité. 

Chaque niveau est chronométré, et le score correspond au temps réalisé : le joueur qui a le temps total le plus bas est classé premier. 

Le jeu comprend un menu de démarrage (choix parmi trois personnages, saisie du nom, choix du niveau, accès au classement) et des effets sonores pour le saut, la mort et la victoire.
